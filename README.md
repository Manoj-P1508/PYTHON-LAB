# Python Programming Lab -- BCA

This repository contains Python Programming Lab exercises for Bachelor
of Computer Applications (BCA) students. It includes **Part A and Part
B** programs covering Python fundamentals, programming concepts,
libraries, file handling, and basic data analysis.

The programs are organized according to the practical lab syllabus and
are intended for learning, practice, and lab reference.

## Lab Contents

### Part A -- Python Fundamentals and Data Handling

1.  **Variables and Arithmetic Operations** -- Declare variables,
    perform arithmetic operations, and display the results.
2.  **Even or Odd** -- Check whether a given number is even or odd using
    `if-else`.
3.  **Fibonacci Series** -- Print the first `n` Fibonacci numbers using
    a `for` loop.
4.  **Vowel and Consonant Count** -- Count vowels and consonants in a
    given string.
5.  **Student Details Using Dictionary** -- Store student details in a
    dictionary and retrieve information based on user input.
6.  **Loop Control Statements** -- Demonstrate `break`, `continue`, and
    `pass`.
7.  **NumPy Arrays** -- Create arrays, perform element-wise operations,
    and reshape arrays.
8.  **Pandas Series** -- Perform indexing, slicing, and querying
    operations on a Series.
9.  **Pandas DataFrame Operations** -- Load a dataset and perform
    sorting and filtering.
10. **Handling Missing Values** -- Detect missing values and fill them
    using mean or median.

### Part B -- Python Programming and Data Analysis

1.  **String Operations** -- Count the occurrences of each word in a
    given string.
2.  **List Operations** -- Insert, delete, and update elements in a
    list.
3.  **Employee Dictionary CRUD** -- Create an employee dictionary and
    perform Create, Read, Update, and Delete operations.
4.  **Prime Number Generator** -- Generate prime numbers up to `n` using
    a generator function.
5.  **Factorial Using Recursion** -- Calculate the factorial of a number
    using recursion.
6.  **File Handling** -- Read and write student marks to a text file and
    display its contents.
7.  **Matplotlib Charts** -- Plot a line graph and a bar chart.
8.  **CSV Data Analysis with Pandas** -- Load a CSV file and perform
    basic data analysis.
9.  **GroupBy and Summary Statistics** -- Group a dataset by category
    and calculate summary statistics.
10. **Scikit-learn Dataset** -- Load a dataset from Scikit-learn and
    display its basic properties.

## Requirements

Install Python 3 and the following libraries for programs that use data
science and plotting packages:

-   NumPy
-   Pandas
-   Matplotlib
-   Scikit-learn

Install the required packages using:

``` bash
pip install numpy pandas matplotlib scikit-learn
```

## How to Run

### Option 1: Run using Python in a terminal

1.  Install Python 3 on your computer.
2.  Download or clone this repository.
3.  Open a terminal or command prompt in the program's folder.
4.  Run the required Python program:

``` bash
python filename.py
```

Replace `filename.py` with the name of the program you want to execute.

### Option 2: Run using Visual Studio Code

1.  Install Python 3 and Visual Studio Code.
2.  Install the Python extension in VS Code.
3.  Open or clone this repository in VS Code.
4.  Open the required `.py` file.
5.  Click **Run Python File** or use the terminal:

``` bash
python filename.py
```

### Option 3: Run using an Online Python Compiler

1.  Open an online Python compiler that supports Python 3.
2.  Copy the program into the editor.
3.  Click Run/Execute.

> Programs that use NumPy, Pandas, Matplotlib, or Scikit-learn require
> an online environment that supports installing or preloads these
> libraries.

## Learning Objectives

By completing these lab programs, students will be able to:

-   Understand Python syntax, variables, data types, and operators.
-   Apply conditional statements and looping constructs.
-   Work with strings, lists, dictionaries, and functions.
-   Implement recursion and generator functions.
-   Perform file reading and writing operations.
-   Use NumPy for numerical and array operations.
-   Use Pandas for Series, DataFrames, and data manipulation.
-   Handle missing data and perform basic statistical analysis.
-   Visualize data using Matplotlib.
-   Explore datasets using Scikit-learn.

## Intended Audience

**BCA students** learning Python programming and introductory data
analysis through practical laboratory exercises.
